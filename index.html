[ 02 / CAPABILITIES ]

Six primitives. Every conversation, observed.

Each capability is a building block you compose visually in the bot builder. No code required for the 80% case — and a clean API for the 20% that needs a custom branch.

01
Intent recognition
Fine-tuned transformer classifies user utterances into 200+ built-in intents with confidence scores. Custom intents train in under 4 minutes.
02
Multilingual routing
42 languages detected automatically on first message. Agents respond in the user's language without explicit configuration.
03
Sentiment analysis
Seven-state classifier tracks sentiment drift across the conversation. Triggers escalation when frustration pattern emerges.
04
Human handoff
One-click takeover with full transcript, AI-generated summary, and tagged moments of friction. The agent stays in listen mode.
05
Analytics & telemetry
Conversation volume, resolution rate, fallback rate, top intents, peak hours — all streamed live, all exportable to CSV.
06
API & SDK integrations
REST + WebSocket API. Official SDKs in TypeScript, Python, Go, Ruby. Webhook events for every state transition.
